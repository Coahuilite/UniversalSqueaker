# ModSettings migration fixtures (§6.2)

## Source and compatibility boundary

The committed `input/` XML files are frozen 0.2.4-shaped migration sources. They are not regenerated by
the verifier: scenarios 02–09 load them with the production Scribe partial, run the production v3/v1 →
v4/v2 transaction, publish a lightweight settings policy, serialize, reload, and run migration again.

- `input/` retains the legacy `targetDefName` record shape and schema 3/voice-pack schema 1 source data.
- `expected/` is the stable v4/v2 output: selection records use `raceDefName`/`xenotypeDefName`; the old
  node is never written. It also records the hidden empty `experimentalRaceAllowlist` Scribe field.
- Scenario 05 locks last-wins de-duplication; 06 retains an orphan PackKey; 07 retains a dormant target;
  08 is the atomic-abort path (invalid scope): the original record lists and old schema must remain intact.

The fixture host links `Source/SqueakyRatkin/SqueakyRatkinSettings.ExposeData.cs` and
`SqueakSettingsMigration.cs`, rather than carrying a second copy of migration behavior. Stubs cover only
the surrounding Scribe/Verse surface.

## Verification and authoring

```text
dotnet run --project tools/SettingsFixtureGenerator -c Release -- --migrate-check
```

Default verification never writes `fixtures/input/`; it proves every expected output is byte-stable after
the second migration pass. When an intentional production migration change requires expected fixtures to
be refreshed, use the explicit authoring mode:

```text
dotnet run --project tools/SettingsFixtureGenerator -c Release -- --author
```

`--author` writes only `fixtures/expected/`; inspect and commit its diffs. The input artifacts must be
replaced only by authentic 0.2.4 ModSettings captures when such captures become available.

## 场景清单（§6.2 八项 + 1 项扩展）

| 场景 | 覆盖 |
| --- | --- |
| 01-new-install-first-save | 无文件新装的 v4/v2 首次持久形态（schema=4、voice-pack schema=2）。 |
| 02-empty-file-no-schema | 无 schema 节点旧配置 → v4/v2 事务迁移。 |
| 03-explicit-off | 显式 Off 节点在迁移后保留。 |
| 04-fallback-seeded | 默认 Fallback + 已播种 Race 选择 → `raceDefName=Ratkin`。 |
| 05-multi-selections-lastwins | 旧 Race/Xenotype selection、同域 last-wins 去重、preset identity 迁移。 |
| 06-orphan-packkey | 不存在的 PackKey 仍保留为 orphan。 |
| 07-biotech-inactive-target | Xenotype selection/preset 身份保留为 dormant 数据。 |
| 08-corrupt-missing-fields | 无效 scope 使整个事务 abort：列表/schema 不变、生产保存桥阻断，legacy source 留待重试。 |
| 09-mood-overrides-and-global-scope | mood dictionary + legacy bool-only global scope 正规化与 schema 迁移。 |

The linked dependencies are production record types, `SqueakyRatkinSettings.ExposeData.cs`,
`SqueakSettingsMigration.cs`, policy/action/logging sources, and Scribe/Verse stubs. The fixture project
does not duplicate migration logic.
