# 0.6 语音管理：当前 UI 合同

当前响应时钟／必需机会事实、混合消费者及旧字段拒绝以[显式机会合同](response-opportunities-0.6-zh.md)为准；普通交互仅真实秒，模拟仅游戏tick，不保legacy或附加tick门。发布前破坏性更新持续至用户明确确认面向玩家公开发布（US06-PREPUBLICATION-COMPAT-20261019 r4），不由GitHub可见／push／tag终止。

当前源码采用“语音管理”首页与“设置与工具”二级页。本文替代旧五工作区、七按钮工具目录与整页帮助编排；配置、十五合同与普通播放政策仍见 [r2 合同](us-kernel-0.6-refactor-zh.md)。本地 Release 候选不是已发布版本，原生外观、窗口、IME、真实 Config 与听感仍需人验。

## 三条路线进入同一窗口

- 启动主菜单 **US 语音 / US Voices**。
- 原版设置类别栏 **US 语音 / US Voices**。
- 原 Mod Settings 重定向，作为隐藏前两项后的恢复路线。

“外观与入口”的 `showMainMenuEntry`、`showOptionsEntry` 独立保存，默认均 true；旧缺字段使用 true，已存 false 保留。它们只隐藏入口，不关闭面板、不改变声音政策。没有 MainButtonDef。

每个原生窗口仅创建一个 `UiHost`。重复打开保留窗口、host、页、域、搜索、滚动和 draft；原生 owner 将同一窗口插到其原有 WindowLayer 的正确最前位置，不跨过更高层确认框夺键。关闭时丢弃仅保留在编辑器内的未发布 draft；Live 已发布值保留，由同一保存 owner 在关闭时 flush／一次失败重试。重开是新会话。

### 原生入口的窄接缝

目标为 RimWorld 1.6.4871（Assembly-CSharp `1.6.9676.17735`）。`MainMenuDrawer.DoMainMenuControls` 的 transpiler 仅替换两个 `DrawOptionListing(Rect,List<ListableOption>)` 调用中的第一个：在游戏选项列表末项前插入 US，再调用原绘制方法。其余 IL、选项相对顺序和网页链接列表保持原样。调用数不是两个则命名警告并保留原菜单，可用 Mod Settings 恢复。

`Dialog_Options.DoWindowContents` postfix 根据官方类别的原过滤规则，在类别列末尾绘制一个本地入口，采用原版 `Widgets.DrawOptionBackground` 灰色类别背景、相同留白与原生不可见按钮命中，不用棕金命令按钮；不创建 OptionCategoryDef，不伪装官方内容，不替换选中类别、设置正文或 OK。没有足够空间或私有 `hasModSettings` 接缝缺失时不覆盖原按钮。重复激活使用缓存的 `WindowStack.windows`／`InsertAtCorrectPositionInList`；缺失时保留已有窗口并报告诊断，不以删窗重建掩盖接缝缺口。目标 build 已定点核对：插层保持本层顺序、不越高层，且安排原生排序更新；只有 GetsInput 允许才手动 focus。实际盖层、输入与其他模组交互仍需原生核验。

## 首页先管理包，不承诺播放

结构为标题与工具入口、真实配置／政策摘要、模式与全局音量、包／加载定义视图、常驻搜索、列表与对象详情。无五区侧栏、指标卡墙或永久 140 高帮助底栏。

P/Q 以独立 pack key 计数：Q 为当前目录身份，P 为至少在一个准确域已选用的目录身份。缺失已存选择另计，并在诊断页逐条列出域和 key，不伪装当前可用包。目录存在、被选中、具备可用声音与实际派发是不同事实；Dispatched 也不是听感收据。普通启动安装后首页说明普通回应就绪，仍按当前模式／选包／条件判断；尚未就绪时显示正常字号警示并直达诊断，状态代码留在诊断。显式开发方案单独说明，不伪装普通默认，也不提供暗启 Dev 的按钮。

单一目标显示精确域开关；多目标包先“查看内容”，在详情逐域开关。标题不批量启用。列表只保留包名、简短来源与目标数，不重复作者和完整覆盖明细；同名同来源时追加 DefName，仍重复则用真实 pack key 作最小辨识。完整作者、DefName、覆盖留在详情。重复行以 pack＋Race＋合法 Xenotype 身份保留节点，不按标签或索引认对象。“正在查看”是包，“正在编辑的目标”是域，目标开关才是选用状态；键盘焦点由原编辑控件持有，不拿同一种高亮冒充四者。详情中当前域状态与不可用／冲突／孤立原因复用生产投影。

复杂筛选可收起，已生效条件和清除始终可见。“已启用”筛选在本次筛选投影中保留原合格行：关掉后实际开关立即变 false，行暂留原位；**刷新或更改筛选／搜索**才重新取成员。每页至多二十包是 US 投影分页，不是 FL 虚拟列表。目录和配置变化沿修订缓存重投影，不逐帧扫描完整目录。

定义浏览来自加载的 ThingDef／Xenotype 目录，不是人口和音频供应反推；无包种族可见，异种操作仍受实际合法域限制。目录“打开”携带准确目标和包身份，不因显示需要改选择或模式。

## 七个二级工具，保留业务权威

1. **行为与来源**：Pawn profile／Race／合法 Xeno 上下文，十五官方与实际 custom 动作、范围、有效值、来源和暂停理由。来源 dropdown 仅对合法域提供目录候选；继承不自动采用唯一候选。当前 action 的稀疏 enabled／interval／volume／pitch／talking／Age／Mood 由实际玩家行读取；空白继承，false 与 0 明确存在。字段编辑保留行中其他参数、响应贡献和模板恢复目标。
2. **预设导入**：保原目标选择和导入结果，只增量复制点名玩家字段；不串改作者来源或包选择。
3. **声音选取与输出**：保距离曲线／预设、彩蛋、谈话、Select 三资格、Eat 三轴；显示实际编辑域，提供行为页的作用域／逐动作音量音调入口。系统音量在首页可达。全局活跃度以可确认的正数输入接同一个 `GameSettings.activity`，默认1，不增加重复的秒数旋钮。
4. **最终回退表**：完整内容宽度和原独立取消层；从对象带 Race 深链。新 race 的 comp admission 仍要求重启，不能用 UI 刷新冒充。
5. **外观与入口**：三套单源数据色板只改角色色，不动字体、几何、滚动或编辑；相机指示器、两个独立入口开关，无独立缩放。
6. **诊断与依赖**：实际版本／固定依赖、缺失选择、日志及几何工具状态。Release 没有 Dev 几何能力时如实不可用，不启 Dev 规避。
7. **恢复设置**：先回当前域编辑器作单行／区域恢复；输出区域恢复独立。全局恢复在末尾折叠且保确认；来源意图／last-good 与独立回退文件仍按 r2 规则保留。

“设置与工具”直接打开本窗口上次工具，首次为行为与来源；不再有七按钮中转目录，也不把记忆写进配置。七类等宽 Button／Wrap 始终可直接切换，宽布局单排、紧凑布局三等列换行，末排不拉伸，不缩字号；包／定义和目录分组等同级导航也等宽。同级切换替换当前工具，不逐次压入返回历史；“返回语音管理”保留包、域、筛选、列表位置和仍由兼容节点持有的编辑上下文。帮助是当前业务正文下方的独立取消层，不替换原页。没有恢复全局五区侧栏。

普通 setter 立即发布，物理保存由 `SettingsSaveOwner` **0.35 秒防抖**。footer 保留 dirty／Saving／Saved／Failed，失败提供显式 Retry。来源与整行字段调用真实 Mod `TryCommitBehaviorSource`／`TryCommitBehaviorOverride`：先原子持久化，拒绝则保旧配置；Committed:RuntimePublishFailed 表示磁盘已提交而发布失败，不自回滚或重复磁盘事务。无全页 Apply、无帧绘写盘。

活跃度 `A` 接受任意有限正数（包括大于便捷刻度范围的既存值），不作滑块夹断，0不是关闭值。后续状态软等待除以A，事件接纳率乘以A且封顶1；硬间隔、资格和供音不变。修改不重建owner、不清保护、不重抽已排等待。声音选取与输出的播放默认恢复将A还原为1，并仅取消受该恢复影响的活跃度草稿；普通全局恢复同样还原1。该入口不启Dev；普通策略在主线程启动就绪时独立安装。

## 帮助按需展开，不离开业务页

页头“本页帮助”固定解释当前页，不读取此前 hover；字段／分组“说明”携带准确 topic 和打开时的 action／domain 对象。帮助是同一 Host 内正文下方的并列底栏，不覆盖业务、不叠窗。关闭时零占位，打开后从实际可分配正文区域取最多三分之一，排除页头、工具 Tab、页脚及本页边距；短文收缩，长文独立 Scroll，标题与关闭固定可见。消费层从公开安排结果读取正文起点、页脚和帮助标题高度，并以真实 ContentRect 的可用底边计算上限，不复制 FL chrome 常量。兼容 Definition 更新保留 Host、节点、业务／帮助各自滚动与草稿。

测绘只解析当前实际显示的译文、宽度与 Small／Tiny 字体，不遍历整目录求最大高度。帮助节点保留对应测量宽度的文字与分段高度快照，Draw 不再重测或把新正文塞进旧空间。未固定的独立消费者不需要 page-state／PreparePage：Draw 观察到主题变化或 grace 到期时只使本节点失效，在下一测量边界采用新正文；当前 pass 仍画已测文字。BeginHelpPass 清除即时 claim 后，上一 Draw 观察到的主题可交给该次测量，session 仍是唯一 15-pass 时钟。显式 pin 始终优先，正常页内发布／PreparePage 会立即测当前题，不被旧 hover 覆盖。宽度或字体环境不匹配时先重新测量再绘字。

当前文字、度量环境、内容／尺寸变化时才重新求底栏预算；不支持环境身份的 metrics 不假定测量可复用。正常固定 topic 不随 hover 改题；其他未固定帮助入口仍读 session 的 15-pass grace。目录 ref、译文 key、binding 分别命名，未知 ref 回原 section，无 section 保空面板规则。

换不同工具页收起帮助；同页换 topic／对象回帮助顶部，同 topic 关闭再开保阅读位置。Esc 先走 FL 内层菜单／capture／编辑取消，再收帮助，最后业务返回。业务取消门在帮助打开时让位，不清业务对象、不提交草稿、不触发音频或来源编辑。

## 三套配色只作用 US

“外观与入口”用一个 Dropdown 选择 **原版深色 `core`（默认）／Royalty `royalty`／黑金 `blackgold`**。选项、命名角色、显式颜色 aliases 仅来自嵌入 `Themes/Palettes.xml`，随 US DLL 交付，加载和校验一次；没有每帧 IO、热监视、额外编辑器或位置索引配置。非法内置数据仅一次可行动诊断，并保可打开的库默认颜色。

三套是当前交付数据，不是解析器的数量上限。解析验证非空集合、唯一 ID、稳定 `core` 默认、完整命名角色与合法颜色；角色还须通过实际 FL API 校验。默认调色板／accent／角色顺序均按 `core` ID 取得，不以文件首项代替默认身份。以后经授权增加配色只需扩同一数据文件，不为数量或排序改解析源码。

原版深色使用深炭底、清楚浅正文与克制金色交互；Royalty 保留夜蓝／暖金风格，是唯一 DLC；全新黑金为近黑底／浅字，金色只强调交互和选中。成功、警告、错误、禁用及 hover／选中分别有命名角色，必要状态同时保留文字／位置／形状。颜色不改字体、密度、控件几何、焦点、滚动或草稿。US widget 通过执行器的作用域绘制；原生入口在 finally 恢复 GUI.color／enabled、字体与锚点，不给整个原版菜单套 US 色板。

`appearanceSwatch` 原本就是字符串。`core`／`royalty` 保留，旧 `ideology`／`biotech`／`anomaly`／`odyssey` 及未知值修复到 `core`，在加载时只标记，主线程启动就绪后沿同一个保存 owner 排队并落盘；不在 GetSettings 期间调用尚未构建的 owner 或 Unity Time。缺省仍省略节点，恢复默认返回 core；不强改合法的 Royalty／黑金。

## 一份状态，两种真实编排

仅使用 Verse 逻辑屏幕与 FL `BeforeDraw(contentRect)`，不另乘倍率、不改 Prefs.UIScale。初始外窗：

```text
W = min(1280, max(960, round(0.8 × Ws)), Ws − 64)
H = min(820, Hs − 64)
```

从实际 FL contentRect 扣本页每边 12 的 padding，**页内宽 ≥1100 且高 ≥640** 才宽布局；在公共页头分配前决定。宽布局详情宽 440、间隔 16，列表取余量（断点处 644）；其余是真单区 drill-down／返回，不把两列压窄。

动态 InitialSizePolicy 由继承的 ResolutionChanged 通知重读；不每帧轮询物理屏幕。收到实际内容尺寸变化时关闭旧坐标 popup／capture；只有跨断点才更新 Definition，同一 host 和兼容节点保留，布局不调用保存／提交。页、域、筛选、列表 scroll 和 draft 都仍由原会话持有。

1024×768@1 与 1280×960@1.25 应紧凑；1366×768 宽而矮、1280×1024 窄而高均紧凑；1920×1080@1 及 @1.25 应宽；1920×1200@1.5 回紧凑。这些是源规则计算的预期，不是实机截图结论。原版拒绝的 1080p@1.5 不作为支持场景。

## 候选人验与证据边界

新增量管线候选消费 FL `local.incremental4 / 833c14f4`，保同一 US Host／manifest／同步调用；有效稳态避免重复完整候选／备份／几何发布，结构与输入变化保留必要完整事务，多根剩余高度依赖在实际改高时保守回完整路径。原 `local.incremental3 / 704c4c1` 未放行，不作为最终输入。原 A009 r2（US `68b30e3`／FL `local.residualcost1 / 36fa7ad`）仍独立体验，原包与收据不变。普通 Release factory、主线程音源／输出接线、已采用节奏和全局活跃度不因本次 FL 接入而改变；不是原生已听到。新旧实际消费身份与边界见[固定输入指南](fl08-consumer-migration-zh.md)。早期失效、首次帮助峰值和性能观察保留各自原输入身份，不用管线计数或源码冗余消除推断首次峰值的唯一根因。

既有 Host 检查使用真实资源／绑定／公开 Execution，但平台是替身；不是游戏字体、窗口栈、配置文件或声音证据。原尺寸场景按上述公式独立计算期望，原页面／帮助场景迁移为首页、直接工具、按需底栏、固定主题及取消，保留 15-pass 合同；不再要求已被替代的 800×600／4:3／永久底栏。宽编排使用固定 RC 要求的正值 Breakpoint，不能用 0 表示不折列。旧教学带和音量／距离快捷卡已不作为可达帮助项；相应能力由首页控件与输出页提供。旧 Core／十五合同／CoreWork 未改部分仍按原输入复用，不用旧 RC 全绿签新 UI。

用户对本地候选仅需先做以下定向检查：

1. 启动无地图，三条路线打开同窗；编辑文字后重复打开／置于其他窗口后再开，核 host 上下文、盖层与关闭策略。两入口分别关闭并重开配置，false 保留，Mod Settings 可恢复。
2. 最小逻辑屏幕与常用宽屏，用同名不同来源、长中英文包名、多目标和已启用筛选执行开关、返回、滚动；确认阻断说明和包操作均可达，同名来源仍可辨。
3. 在合法分辨率／倍率间跨断点，保未提交字段、已发布 Live 值、页／域／搜索／scroll；确认取消倍率后恢复，旧 popup／capture 不穿透。
4. 在工具间直接切换并返回语音管理；先 hover 其他字段再点“本页帮助”，应仍到当前页主题。字段“说明”须点名正确字段／目标，底栏上限、短文收缩、长文滚动和 Esc 层级正确。工具间切换再返回须保上下文；三色板即时换色但控件不移动。来源／行字段的保存失败与已保存但无法应用应有不同结果说明；普通保存的 Retry、Remix、真实 Config／IME／听感分别记录，不能以 exit0 代签。

### 页内无法点击时的一次性能摘要

观测默认关闭，不依赖打开 Dev 播放政策。现有“详细日志”明确设为 Enabled 后，新开设置窗口会采样至32个 Host IMGUI pass，或在提前关闭时输出 partial；Auto／Disabled 不采样。一个 pass 是 `UiSession.BeginFrame` 的一次推进，不是渲染帧／秒。FL 的 `TimingSampleFrames=1` 只把每次实际 arrange／draw 调用的计时放进已有缓冲；US 先 drain 并合并这些事件，停止时各写一条阶段摘要，再写一条创建／视图读取与重建摘要，不逐 pass 写日志。`samples` 是实际收到的该阶段调用数，不预设与 `passes` 相等；额外测量、恢复绘制或缓冲保留范围都会影响它。Close 在释放 Host 前先收取已完成阶段，未完成调用不算已取得样本。

若不能操作 US 页内控件，可由用户／维护者完全退出游戏后，备份并编辑**现有** US 设置 XML。文件名沿 `Mod_<模组目录名>_SqueakerMod.xml` 规则；安装目录名为 UniversalSqueaker 时对应 `Mod_UniversalSqueaker_SqueakerMod.xml`。在现有 `SettingsBlock/ModSettings` 内，将唯一的 `diagnosticLogging` 设为：

```xml
<diagnosticLogging>Enabled</diagnosticLogging>
```

这是 `GameSettings.devLoggingMode` 的现有序列化字段，枚举值为 Enabled（1），不是 `<devLoggingMode>`；字段缺省是 Auto。只在已有 ModSettings 内补／改这一项，保留 `responseConfigurationFormat` 及其他配置，不创建整份文件、不迁入旧设置。若找不到当前设置文件或格式标记不是1，先交维护者确认。

使用维护者提供的新配对包启动后，只开一次 US 窗口，尝试原短路径并关闭；维护者收该次 Player 日志中的 `UI.cost` 摘要。提前关闭可收 partial，零样本按零样本解释。结束后再次完全退出游戏，将该字段恢复原值（原来缺省则移除本次新增项），不要用整份旧备份覆盖期间其他修改。此操作由用户／维护者执行；工程检查没有读取或修改真实 Config。

定点分项沿同一32-pass窗口记录：`metrics` 给出传入原生度量器的高度／宽度度量、字体环境捕获的次数与累计／最大耗时；字体环境身份原样透传，不改变缓存资格。两条 `us_draw` 给出首页模式行与包行状态面的实际 Draw 次数和包含成本；零calls表示未取得该控件样本，不能据此说它成本低。采样停止后计数关闭，度量继续透传，不逐次写日志。`fit_enabled_at_start` 标明开窗时文字适配诊断是否开启；fit所用的度量包含在metrics内，并未独立计时，不能把全部文字成本都归给fit。自定义Draw包含其内部文字／fit／控件工作，与metrics可能重叠，不能相加成总帧耗时。

arrange／draw摘要不含FL绑定owner刷新、同步、Enter及US壳前工作／保存；低值不能排除这些成本。窗口从开窗开始计数，不保证包含较晚发生的按钮动作；`UI.cost`后才出现的动作不能算本次已测。当前原生证据已确认布局／绘制耗时较重，但尚未完成性能根因与修复验收。
