## Contract decisions

- Slice 选择 `chrome/banner` + `input/stepper-slider`，因为它同时覆盖真实资源、核心 registry、typed getter/setter、布局和原生控件绘制；不引入 US 业务命令桥。
- `global-volume` 是 XML `Widget.Id`、binding key 和 Settings 字段映射的唯一切片语义；binding 类型固定为 `float`。
- `UiHost` 由 `UniversalSqueakerSettingsWindow` 字段持有；不是测试中临时 `new`。每个窗口一个 Host/session，关闭释放，重开由新窗口创建新 Host/session。
- Kernel slice 位于旧完整 Settings 页面上方，旧页面在 Gate U 前保留为明确 fallback/未迁移路径；失败只隐藏 Kernel slice，不阻断已有设置页面。
- Host 新增 `DrawFrame`，集中保证 `BeginFrame -> Measure/Arrange -> Draw -> EndFrame` 的同步边界；异常仍由生产窗口捕获并释放当前 Host。
