# v0.6.0-rc1 — release-candidate scope / 候选范围

## English

RimWorld **1.6 only**. This is a prerelease, not Latest. The paired baseline passed overall internal trials; coverage of individual actions, IME, native Config and screen combinations remains limited.

- Ordinary Release responses initialize without Dev mode. One platform-free Core and synchronous owner cover all fifteen declared actions, precise subjects and explicit event consumers.
- Accepted Select uses 0.3 real seconds; Draft/Undraft each 0.6. Simulation uses game ticks. Explicit accepted-operation facts prevent stale/repeated-root replay; no silent legacy clock fallback or reinterpretation of old units.
- Voice management has direct secondary tools, contextual bottom help, independent complete category/source/query paging, explicit fallback-table creation and three data palettes. At a logical 1024 × 768 resolution, the window opens centred at 864 × 640. Vanilla Options has a packaged microphone entry.
- US ships no voices and no prerequisite DLLs. Install Harmony and the **paired FerriteLib release named in the version identity**, both before US.

### Upgrade and recovery

Back up your configuration yourself before upgrading. The 0.6 declaration/configuration/API boundary is breaking: update author examples and fields to the [current contract](../openspec/specs/response-opportunities/spec.md). Old timing fields are rejected, not converted to seconds or executed. Unchanged pack/audio/appearance data is not cleared. On the exact selected domain, explicitly choose inheritance or rebind an updated source, including the same source ID; a failed atomic commit retains the original data. General malformed XML is not auto-repaired. A rollback needs the corresponding older configuration, not an attempt to run new fields on the old DLL.

Native sound still requires applicable supply, race admission, qualification, player enablement and normal protection/resource readiness. Table-only new race admission requires a full restart. Uninstall remains save-safe: US writes no persistent save data; external settings/profiles remain in Config.

## 中文

仅支持 **RimWorld 1.6**；rc1为预发布、非Latest。配对基线已获内部试玩总体接受；逐动作、输入法、原生Config与屏幕组合的覆盖仍有限。

本版包括普通Release自动装配、中立Core/单owner的十五合同、真实接受交互秒与模拟tick分道、显式消费者、精确拒绝旧字段及定域原子恢复。UI采用语音管理首页/直接工具/按需帮助、完整独立筛选分页、显式创建回退表、三色板、864×640紧凑外窗及原版设置麦克风入口。

升级前由玩家备份配置，作者按当前合同更新声明/API；不把旧tick数当秒、不自动转换、不清整份用户文件。选定准确域后明确继承或重绑已更新来源，失败保原数据。未改语义的包、音频、外观保留；一般畸形XML不自动修复。回退使用对应旧配置。US不附带语音或前置DLL，Harmony与实际配对FerriteLib独立安装；声音仍受供音/资格/禁用/保护和资源就绪条件约束。
