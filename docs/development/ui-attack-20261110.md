## F06：关闭终态与借用释放

FL 在实际 `PreClose` 标记当前生命周期结束；chrome、BeforeDraw、factory、attach、DrawFrame 等
相邻出口核本次身份，关闭后不再继续该 pass。`PreOpen` 记住实例已进入原生生命周期，关闭后的
迟到 draw 不能重开；只有原生 PreOpen 恢复。独立直接实例的首次绘制，以及外部 PreClose 完成后
下一独立顶层 WindowOnGUI 重开均保留。活动 contents 深度和关闭回调深度阻止同 pass/释放过程重入；
新生命周期清失败态并取得新 Host/session。无新开关、caller 前提或笼统 !IsOpen 护栏。
关闭 veto 不标终态；BeforeDraw 故障仍进入原延后一 pass 的 notice 路径。

US 的 HostDetached 先完成既有采样，再在 finally 解除 source 的 host/revision、派生视图及
report 请求，清采样/Dev target、audit 和 Remix flow。source 的 Host-root release 还覆盖直接
Host factory 使用，没有给独立调用加 WindowStack 前提。窗口 PreClose 即使前置收尾失败也
进入 FL 释放；audit 的强引用登记及 fit 引用计数在最终 drain 失败时仍解除。

修订记录：本任务 a001 给独立直接重开新增 PreOpen 前提，五条既有断言失败；PM 不批准该限制。
a001-r2 已按原合同恢复，完整 `KernelPageLifecycleTests` 及其中五条断言通过，未改测试。
a001 的包、Source Form、exit5 证据保留，不将其改写成已接受；r2 是新的完整双根配对。

保存 Flush/publication、0.35 秒防抖、失败恢复和业务读写未改；源借用解除不销毁 settings。
原日志定位 disposed-source 路径；本次旧 response 配对实机还复现 chrome 关闭后、显式重开前
再次 CreateHost。最终候选六次 chrome 关闭均清空 Host，只有后续显式打开才建立新 session；

## F07：每次合法变值仍发布，但不重复解析/复制无关输入

每次发布仍捕获当前全部公开 settings 字段、玩家行和音包选择，仍推进配置身份并排队保存。
只有 XML 完全相等且已有成功解析结果时，新的不可变配置复用其私有来源树；不采用仅换音量、
漏掉外部直接修改的快照捷径。已捕获的 sealed 玩家行本身不可变，无需再经 Read 复制后二次复制。
按动作和层一次分组，Resolve 不再为每个动作扫描、排序全部玩家行。

来源目录在创建时复制输入并建立候选索引；重复 ID/动作仍被排除。公开 Candidates/Find 仍返回
独立副本。内部 resolver 只借用私有不可变目录中的目标来源，不再为每个动作复制整域所有候选。
完整动作视图也在一次 BuildView 内对当前域的玩家行分组，own 值与 preset anchor 共用该组；
公开直接 ReadPlayerActionOverride 保持每次鲜读。没有跨发布缓存可变 settings 或跳过整个视图。

## Release 的操作采样可覆盖输入和尾段

保留原「采样当前设置页」32 Host-pass 入口；它通常太短，不能用于抢首次展开或输入停止。

layout trace预算，不更改业务设置、默认日志策略或关闭后生命周期。

在获准的测试实例中使用：
1. RimWorld 自带开发者模式开启后，US「系统 → 诊断 → 开发者工具 · 展开／收起 → 打开开发面板」，
   目标选「设置页」。先在设置窗口定位音量框或所需高级参数行，保持同一 Host。
2. 点击「开始20秒操作采样」，在该窗口执行一种操作：合法音量变化、上限继续输入，或同一行首次/快速开合。
   先操作再停止，留出数秒尾段；无需抢32 pass，也不要在开窗时就开始。
3. 点「结束并保全采样」或等20秒自动结束，保留日志中该 session/sample 的 `UI.cost` 开始、完成及汇总行。
   需要 detail/fit 关闭对照时使用 Release 的自动/关闭日志模式，仍点击新入口；看报告实际 fit/detail 状态，
   其他活窗口可能仍持有全局 fit，不把「采集关闭」（仅几何）当作 fit 关闭。

KeyDown 不是 OS 输入完成/IME 完成标记，20秒汇总也不提供逐帧 FPS、GC 或物理保存耗时。
