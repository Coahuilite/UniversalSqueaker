# 正式UI消费、上下文与布局
状态：现行，US0.6.x。责任：US UI消费维护者。配置／提交与默认分别由CFG／PUB／POL拥有；本页只约束它们如何被真实界面消费，不另建业务规则。

UI-10 于2026-11-11按 WO-FL09-RETAINED-DISPLAY-20261111 r2 **正式采用**，仅适用于 `feat/rw16-fl09-display-snapshot-20261111` 的RW1.6／FL0.9消费。UI-01至09保持；[原change](../../changes/rw16-fl09-display-snapshot/proposal.md)为历史与接线设计，不是另一份current。r3已核定两库独立采用提交并放行实现；工程候选／检查与待验见[任务](../../changes/rw16-fl09-display-snapshot/tasks.md)，采用不代替原生接受。

## Purpose
从原生入口到包管理、直接工具和显式帮助，保同窗上下文、准确对象与可用输入。本文描述已定消费合同，不发起新的全局UX或工具页重做。

## Requirements

### Requirement: UI-01 三条路线进入同一窗口
US界面 SHALL履行以下已定消费与状态规则。

- 启动主菜单 **US 语音 / US Voices**。
- 原版设置类别栏 **US 语音 / US Voices**。
- 原 Mod Settings 重定向，作为隐藏前两项后的恢复路线。

“外观与入口”的 `showMainMenuEntry`、`showOptionsEntry` 独立保存，默认均 true；旧缺字段使用 true，已存 false 保留。它们只隐藏入口，不关闭面板、不改变声音政策。没有 MainButtonDef。

每个原生窗口仅创建一个 `UiHost`。重复打开保留窗口、host、页、域、搜索、滚动和 draft；原生 owner 将同一窗口插到其原有 WindowLayer 的正确最前位置，不跨过更高层确认框夺键。关闭时丢弃仅保留在编辑器内的未发布 draft；Live 已发布值保留，由同一保存 owner 在关闭时 flush／一次失败重试。重开是新会话。

#### Scenario: 重复进入已有窗口
- **WHEN** 通过任一入口再次打开
- **THEN** 保同一host与编辑上下文，仅在原WindowLayer合法置前，不越高层确认夺键


### Requirement: UI-02 首页先管理包，不承诺播放
US界面 SHALL履行以下已定消费与状态规则。

结构为标题与工具入口、真实配置／政策摘要、模式与全局音量、包／加载定义视图、常驻搜索、列表与对象详情。无五区侧栏、指标卡墙或永久 140 高帮助底栏。

P/Q 以独立 pack key 计数：Q 为当前目录身份，P 为至少在一个准确域已选用的目录身份。缺失已存选择另计，并在诊断页逐条列出域和 key，不伪装当前可用包。目录存在、被选中、具备可用声音与实际派发是不同事实；Dispatched 也不是听感收据。普通启动安装后首页说明普通回应就绪，仍按当前模式／选包／条件判断；尚未就绪时显示正常字号警示并直达诊断，状态代码留在诊断。显式开发方案单独说明，不伪装普通默认，也不提供暗启 Dev 的按钮。

单一目标显示精确域开关；多目标包先“查看内容”，在详情逐域开关。包名与内容按钮相邻，准确目标与开关相邻，剩余宽度留在组外。标题不批量启用。无歧义单目标不附加整行作者或来源；同名、异常、多目标才补最小辨识，完整作者、来源、DefName和覆盖留详情。长文本正常字号换行，列表和详情独立滚动。重复行以pack＋Race＋合法Xenotype身份保留节点，不按标签或索引认对象。查看包只改变查看身份，明确点域才切编辑目标，开关才写该准确域。当前包和域均从未过滤事实解析，隐藏对象保原身份和供给；无包、未加载、Biotech关闭、缺失选择与条件遮挡分明。返回列表与该层Esc保查询、页码、滚动和查看身份；显式取消选择另有含义，内层编辑／弹层／帮助仍优先。

包头与目标行 SHALL以自身文字和控件的自然高度参与列表；首项和后续项遵循同一规则。选中／悬停底板只跟随MatchContent，不制造独立行高。横向未占用宽度留在信息组外，不用同时消费纵向余量的空Fill容器占位，不硬编码首项高度、缩字号或改窗口断点掩盖空高。

详情 SHALL分别消费查看包与真实编辑域。没有查看包时只给短引导，不重复元数据或说明；没有合法可操作域时不显示“正在编辑”占位或无对象业务按钮。查看包不决定编辑资格，也不清已有独立域或来源；行为入口按真实Race／合法Xeno域，回退入口按实际父Race资格，显示、CanExecute与导航采用同一判定及准确身份。

包页默认类人且HAR优先；准确Human由加载Def对象身份确认，独立HAR类人范围排除Human。动物、其他、全部均可主动到达。复杂筛选可收起，范围、非默认条件、符合包数和本查询清除始终可见，关键词不重复为条件标签。Race／Xeno／作者候选独立有界搜索与翻页；输入搜索不选首项。无包Race／Xeno保候选和准确空态，无父域Xeno不编Human；未限定Race时同一Xeno Def合并，显示真实供包父域，同名不同Def按真实来源辨识。清除回包页类人默认，不清编辑目标／查看包／选包／行为来源。“已启用”在本次筛选投影保原合格行，关闭后真实开关立即false，刷新或更改筛选／搜索才重取成员。每页至多二十包是US投影分页；符合包数与全局P/Q分开，不逐帧扫描完整目录。

定义浏览来自加载的 ThingDef／Xenotype 目录，不是人口和音频供应反推；无包种族可见，异种操作仍受实际合法域限制。目录“打开”携带准确目标和包身份，不因显示需要改选择或模式。

#### Scenario: 已启用筛选内关闭一项
- **WHEN** 玩家关闭合格行
- **THEN** 实际开关立即false，当前筛选快照暂留行；刷新／更改查询才重取成员


### Requirement: UI-03 目录与回退表：先筛选，再翻页
US界面 SHALL履行以下已定消费与状态规则。

首次目录显示类人种族和加载异种；“仅种族／仅异种／HAR类人／准确Human及其真实供包异种／动物／其他／全部”是独立范围。HAR只决定框架标签与排序，不允许动物或机械越过默认生命类别门。没有Biotech时异种目录为空。加载异种的浏览身份不授予任意Race域操作权限；无真实父域保持独立身份。返回包列表再进目录及目录到达后返回，保关键词、类别、来源和页码。

关键词同时匹配名称、DefName和来源；来源筛选值是实际Def的packageId，显示模组名，同名追加ID。Core与每个DLC是不同来源，异种按自身XenotypeDef来源，不按基因或声音包归属。来源展开后可搜索，每页五项；结果每页八项，完整筛选排序后再分页。摘要对比符合数与完整合法总数，清除回本页默认。

已建回退表、新建Race候选与Core声音各有独立查询／来源／页码；已建表默认全部，Race候选默认类人，均可主动选择动物或其他生命类型。回退表不混入Xenotype。候选排除全部已建表，选择候选仅记录目标，明确按“创建”才落盘。筛选、来源和翻页都不落盘。当前编辑对象即使被筛掉或不在当前页，仍明确显示并保持原目标；选择另一表才切换编辑对象。

回退无表深链保目标，明确显示创建路径，不显示别的首表。保首次默认表时，仅在明确进入动作一次确认并同步state；投影、清除和翻页不自动采用。显示条目和声音写入共用同一已确认表身份，无确认表不暴露条目写入。来源选择器自己的搜索清除只清来源查询，不清当前列表或目标。

Core声音先取完整合法库存，再按关键词／来源筛选和排序，八项一页；不再不可达地截断前四十个声音或前二十个Race。声音不套生命类别，也不因此开放其他模组音源。每个窗口复用已发布定义快照，Core声音库存按该快照捕获；稳定Draw不重扫DefDatabase。新建Race接入仍需完整重启。

#### Scenario: 超过原前20／40库存
- **WHEN** 玩家翻页或搜索完整合法Race／Core声音集
- **THEN** 所有符合结果可达；选择新Race候选不落盘，明确创建才写


### Requirement: UI-04 分组导航，保留七类业务权威
US界面 SHALL履行以下已定消费与状态规则。

1. **行为与来源**：Pawn profile／Race／合法 Xeno 上下文，十五官方与实际 custom 动作、范围、有效值、来源和暂停理由。来源 dropdown 仅对合法域提供目录候选；继承不自动采用唯一候选。当前 action 的稀疏 enabled／interval／volume／pitch／talking／Age／Mood 由实际玩家行读取；空白继承，false 与 0 明确存在。字段编辑保留行中其他参数、响应贡献和模板恢复目标。
2. **预设导入**：保原目标选择和导入结果，只增量复制点名玩家字段；不串改作者来源或包选择。
3. **声音选取与输出**：保距离曲线／预设、彩蛋、谈话、Select 三资格、Eat 三轴；显示实际编辑域，提供行为页的作用域／逐动作音量音调入口。系统音量在首页可达。全局活跃度以可确认的正数输入接同一个 `GameSettings.activity`，默认1，不增加重复的秒数旋钮。
4. **最终回退表**：完整内容宽度和原独立取消层；从对象带 Race 深链。新 race 的 comp admission 仍要求重启，不能用 UI 刷新冒充。
5. **外观与入口**：三套单源数据色板只改角色色，不动字体、几何、滚动或编辑；相机指示器、两个独立入口开关，无独立缩放。
6. **诊断与依赖**：实际版本／固定依赖、缺失选择、普通回应诊断入口、日志及几何工具状态。回应窗口的显式单目标记录、复制和生命周期由 DIAG-06／07 拥有；打开后正常关闭暂停游戏的设置窗，不暗关草稿。Release 没有 Dev 几何能力时如实不可用，不启 Dev 规避。
7. **恢复设置**：先回当前域编辑器作单行／区域恢复；输出区域恢复独立。全局恢复在末尾折叠且保确认；来源意图／last-good 与独立回退文件仍按 r2 规则保留。

主导航 SHALL按**语音／调音／系统**分组。调音内为行为与来源、输出、回退表、预设；系统内为外观与入口、诊断与依赖、恢复设置。进入组恢复该会话上次页面，首次调音进入行为与来源；没有七按钮中转目录，不把组内记忆写进配置。同组按钮保持一致层级，按区域内容宽度编排，不跨组拼成七项等宽工具墙，也不为填满宽窗拉伸短控件。主导航、页标题、组内页签与正文层级分明；包／定义与目录分组仍以等宽按钮表达同级关系。同级切换替换当前页，不逐次压入返回历史；返回语音保包、域、筛选、列表位置及兼容编辑上下文。帮助仍为当前正文下方的独立取消层，不替换页面，不恢复全局五区侧栏。

footer SHALL对应PUB显示dirty／Saving／Saved／Failed，失败保显式Retry；普通排队不称Committed，原子已提交与发布失败分开。无全页Apply、无Draw写盘。

活跃度编辑消费POL-03，提供有限正值与有效来源，不增加重复秒数旋钮；仅取消受本区域恢复影响的草稿。

诊断查询空词回当前视口追踪行，非空词为有界当前地图搜索，最多返回64项并明确截断；返回数不是完整地图总数。就近清除只清诊断关键词并回第一页，保详情／记录目标。搜索不选择Pawn；点击视口内或地图搜索结果都只更新面板 browsing Pawn，不调用原版 Select，也不自动锁定或开始录制。Start 才交给原单目标 capture owner，Stop 明确停止当前录制对象。窄屏返回保原查询、页码及列表／详情各自滚动，技术全文使用独立阅读视图。原生IME、焦点与听感以实际证据单独验收。

#### Scenario: 工具切换与未提交草稿
- **WHEN** 同级工具直切再返回包管理
- **THEN** 保兼容节点的上下文和滚动；普通保存与原子结果沿PUB，不添加全页Apply


### Requirement: UI-05 帮助按需展开，不离开业务页
US界面 SHALL履行以下已定消费与状态规则。

页头“本页帮助” SHALL 是同一入口的开关，打开后显示“收起帮助”。首次打开先显示当前页总览，随后真实字段／标签／只读上下文的有效 hover 更新当前问题；进入帮助阅读或滚动时保留最近内容，下个有效 hover 才替换。关闭时 hover 不自动打开。同语境重开保适用阅读位置；新 topic 或准确对象回顶部。纯说明 i／逐字段说明按钮退出，展开参数、技术详情、来源与恢复操作保留。显式上下文入口直接显示指定内容，不误作关闭。

帮助是同一 Host 内正文下方的并列底栏，不覆盖业务、不叠窗。关闭时零占位，打开后从实际可分配正文区域取最多三分之一，排除页头、工具 Tab、页脚及本页边距；短文收缩，长文独立 Scroll，明确当前字段／对象的标题与关闭固定可见，不重复多层祖先标题。正文使用既有 16 逻辑字号；14 只用于辅助对象元信息。消费层从公开安排结果读取正文起点、页脚和帮助标题高度，以真实 ContentRect 的可用底边计算上限，不复制 FL chrome 常量。兼容 Definition 更新保留 Host、节点、业务／帮助各自滚动与草稿。

显式采用非提交预算的完整窗按[PREVIEW-07](../developer-preview/spec.md#requirement-preview-07-显式采用的预算测量不提交布局)先求当前帮助预算，再交正式排列／合法scroll clamp；旧未启用路径保原使用条件。兼容scroll保留不意味着禁止内容变短后的合法钳制。

标题、正文、对象上下文与量高 SHALL 消费同一当前展示状态。只解析实际译文、宽度、有效字体及度量环境，不遍历目录求最大高度。帮助节点保留对应测量宽度的文字和分段高度快照；新 presentation 先使节点失效，在下一测量边界采用，当前 pass 仍画已测文字，不能把新长文塞入旧空间。不支持环境身份的 metrics 不假定测量可复用。

独立的显式 pin 消费者保原优先级、准确 context 和寿命。没有 page-state／PreparePage 的未 pin 独立消费者仍读 session 的 15-pass grace；它们不被强制采用正常页内 follow／reading-hold。session 是唯一 hover/grace 时钟，effective ref/source 不冒充新鲜命中。目录 ref、HelpItem.LabelKey／TextKey、binding 地址分别命名；不按显示标签、Value 或行号猜 ref。无选项专属帮助时保一般帮助；跨 section 显式 ref 仍可查目录；未知 ref 回原 section，无 section 保空面板。

换不同工具页收起帮助。Esc 先走 FL 内层菜单／capture／编辑取消，再收帮助，最后业务返回；不清业务对象、不提交草稿、不触发音频或来源编辑。

#### Scenario: 独立未pin帮助主题改变
- **WHEN** hover／15-pass到期使独立 consumer 的 session 主题变化但旧测量复用
- **THEN** 当前 pass 仍画已测文本，局部失效后才采用新文本；正常页内阅读则保持最后内容，新的有效 hover 才替换

### Requirement: UI-06 三套配色只作用 US
US界面 SHALL履行以下已定消费与状态规则。

“外观与入口”用一个 Dropdown 选择 **原版深色 `core`（默认）／Royalty `royalty`／黑金 `blackgold`**。选项、命名角色、显式颜色 aliases 仅来自嵌入 `Themes/Palettes.xml`，随 US DLL 交付，加载和校验一次；没有每帧 IO、热监视、额外编辑器或位置索引配置。非法内置数据仅一次可行动诊断，并保可打开的库默认颜色。

三套是当前交付数据，不是解析器的数量上限。解析验证非空集合、唯一 ID、稳定 `core` 默认、完整命名角色与合法颜色；角色还须通过实际 FL API 校验。默认调色板／accent／角色顺序均按 `core` ID 取得，不以文件首项代替默认身份。以后经授权增加配色只需扩同一数据文件，不为数量或排序改解析源码。

原版深色使用深炭底、清楚浅正文与克制金色交互；Royalty 保留夜蓝／暖金风格，是唯一 DLC；全新黑金为近黑底／浅字，金色只强调交互和选中。成功、警告、错误、禁用及 hover／选中分别有命名角色，必要状态同时保留文字／位置／形状。颜色不改字体、密度、控件几何、焦点、滚动或草稿。US widget 通过执行器的作用域绘制；原生入口在 finally 恢复 GUI.color／enabled、字体与锚点，不给整个原版菜单套 US 色板。

`appearanceSwatch` 原本就是字符串。`core`／`royalty` 保留，旧 `ideology`／`biotech`／`anomaly`／`odyssey` 及未知值修复到 `core`，在加载时只标记，主线程启动就绪后沿同一个保存 owner 排队并落盘；不在 GetSettings 期间调用尚未构建的 owner 或 Unity Time。缺省仍省略节点，恢复默认返回 core；不强改合法的 Royalty／黑金。

#### Scenario: 增加数据色板而默认顺序改变
- **WHEN** 数据包含合法新ID且core不在首项
- **THEN** 仍按稳定core默认，数量不写死；当前交付仍仅三项


### Requirement: UI-07 一份状态，按区域选择真实编排
US界面 SHALL履行以下已定消费与状态规则。

仅使用 Verse 逻辑屏幕与 FL `BeforeDraw(contentRect)`，不另乘倍率、不改 Prefs.UIScale。初始外窗：

```text
W = max(1, min(1280, max(864, round(0.8 × Ws)), Ws − 64))
H = max(1, min(max(640, min(820, Hs − 128)), Hs − 64))
```

1024×768逻辑屏幕外窗为864×640，居中后左右80／上下64；更小屏幕按可用空间钳制，不强保下限。标题高36、无重复品牌副标题；普通状态并入包摘要，异常仍显式指向诊断。标准首页以三包完整名称／目标／启用状态为原生验收目标，更多包滚动。

从实际 FL contentRect 扣本页每边12的padding，令 Wp=contentRect.width−24、Hp=contentRect.height−24，在公共页头分配前决定。普通WideLayout为 **Wp≥780且Hp≥440**；名册RosterIsWide独立为 **Wp≥900**，不另加高度门。名册宽时列表300、间隔12、详情取余量且内部内容上限660；最终回退表宽时列表max(300,min(400,0.4×Wp))、间隔12、详情取余量且上限660。窄时是对应区域完整单区drill-down／返回，不压窄两列；保各自查看／编辑身份、查询／页码／滚动。子控件按自身实际宽度的断点编排，不套一个全窗标签。

动态 InitialSizePolicy 由继承的 ResolutionChanged 通知重读；不每帧轮询物理屏幕。收到实际内容尺寸变化时关闭旧坐标 popup／capture；只有跨断点才更新 Definition，同一 host 和兼容节点保留，布局不调用保存／提交。页、域、筛选、列表 scroll 和 draft 都仍由原会话持有。

分辨率／UI倍率先经游戏规则形成逻辑屏幕及contentRect，不能直接代替上述区域判定；不沿用旧1100×640断点的分辨率标签表。游戏允许的倍率以实际宿主为准。此处补录已采用B/r6基线，原1.6渲染与输入待验保持。

#### Scenario: 内容尺寸跨断点
- **WHEN** 实际contentRect改变，使普通Wp≥780且Hp≥440或名册Wp≥900判定改变
- **THEN** 对应区域选择并排或真单区，而非压窄两列；同host保页／域／草稿／滚动，旧坐标popup与capture关闭

### Requirement: UI-08 正式页面可同源预览
开发辅助 SHALL遵守[同源开发预览](../developer-preview/spec.md)，复用真实页面、绑定、编辑与寿命，隔离样例与真实设置。当前区域预览不冒充完整游戏窗口。
#### Scenario: 脱机查看高级参数
- **WHEN** 人或agent进入作者注册的行为页
- **THEN** 看到同源布局与明确样例状态；真实配置不因预览被修改

### Requirement: UI-09 紧凑行为行与可读层级
行为列表 SHALL把动作名、范围／有效状态与展开入口组成同一摘要行；窄时先让名称与控件组分行，再按组内空间堆叠，不给短标签分掉半窗、留下无用途空白。展开内容紧随对应动作，保稳定Repeat／字段身份；字段按机会与间隔、输出倍率、响应参与等实际语义分组，恢复动作邻近其作用域。

正文与编辑仍用可读的常规字号；当前正文16逻辑字号、辅助元信息14沿既有主题，不能缩字掩盖布局问题。组内间距紧凑、组间间距清楚，长译文按原度量自然换行；含义、单位、继承／显式值和最终生效值可辨。低频技术来源用详情，解释用现有按需帮助／hover，不到处新增小标签或逐项i按钮。无合法来源选项时隐藏空控件行，保标题与实际原因，不制造空白dropdown占位。

SR与旧US仅作外形和指定控件排列参考；不复制品牌、资源、业务或整套页面。精确宽度和断点在作者布局中管理，不写入FL通用默认；已交实现及不同消费线差距见实现状态。
#### Scenario: 同一动作从宽区变为窄区
- **WHEN** 行内可用宽度减少或高级参数展开
- **THEN** 名称、范围与展开入口按原组关系换行，详细字段保持正常字号／单位与原编辑路径；收起不清已发布值或兼容草稿

### Requirement: UI-10 生产 F09 显式保留准备，原生操作保持实时

本条 SHALL 仅在独立 `feat/rw16-fl09-display-snapshot-20261111` 分支采用 **FL API [0.9.0,0.10.0)／RW1.6 net472**；旧0.8分支范围、载体与保证不变。US 消费 FL 已选定的新区域 capability（新增接缝 Public-unstable），不以另一库的产品提交是否已到位代替本条消费保证；API 定义及兼容等级仍由 FL 唯一拥有。

US SHALL 在真实 `GameSettingsWindow → UsKernelSettingsHost.Create → b-actions` 路径显式消费已采用的 FL0.9 保留展示合同，不建立第二份页面、字段身份或 FL 公共 API。新资格仅属于明确采用的来源／作用域，不能由普通 BindValue、已有 view identity、Bump 或“本页调用”自动推断。

US SHALL 由每 Host 的生产 F09 准备 owner 组合完整当前输入：配置／定义／policy／目录与实现可用性、实际 own／effective 与来源意图、准确层／域／action、贡献 keys、row-result、本窗 details／timing／选择状态及译文／格式文化。它 SHALL 自动观察仍由旧读面可见的可变输入，并在所有自有写边更新失效；失败提交也在内。不能以公开旧写入口额外 Notify、Host、展开状态或预热为新前提。外来／不能闭合的来源继续原 fallback。来源观察与未映射普通读 SHALL 按当前父可见性、tab／Repeat 活动域进行；父隐藏后不得探读历史子 getter 来证明未变。完整成员及其顺序仍取实际 canonical／贡献来源，不凭旧条目数或对象引用冻结。

US SHALL 将已采用 FL 合同中由原 editor／native owner 提供的 draft、valid／modified、焦点／IME、提交／取消／冲突、popup／capture、scroll／clip／hit 与窗口／环境失效作为独立当前事实。若该条来源未闭合，对应作用域不得取得完整准备复用资格，原路径继续可用。US model view 没变不代表这些事实没变，不能自行缓存 native editing 的结果或复用旧 hit 凭据。

准备数据／派生几何／展示描述、必须运行的原生操作、Repaint 实际提交 SHALL 分开：未变作用域在展开后停手时不再逐现场 21 个字段重做业务投影、格式化、测量／布局验证或 widget 展示准备。允许在合法边界作完整的 root 输入观察，但不能把同一逐字段派生移入“快照捕获”再称省略。字段数由真实 canonical／贡献集合决定，不写死 21 或删减字段。

纯准备 SHALL 只消费明确映射的不可变表示及合法的当前 UI／环境事实，不回普通 getter 补数据。不可变 choices SHALL 使用与 value 区分的独立 snapshot 只读通道，二者允许同 key；相应 root／item 的 choices、caption／help 和顺序均由完整来源覆盖。即时资格、当前模型读回、请求与原普通 Choices／Get 的含义不改，未映射的旧读仍按原条件执行。

每个所需 native callback SHALL 仍完成原 ID 次序、资格、编辑、按键、读回、帮助、capture、scroll/hit 等操作；新准备／重排不得重放业务请求。IMGUI 后端在必要 Repaint 仍提交当前内容；只有有效裁剪为空，或已证明全部实际绘制范围被裁掉（含强制裁剪将其裁尽）时，才可延期该纯 Paint。layout rect 本身不证明自定义控件的实际绘制范围；越界绘制范围不确定时 SHALL 照常绘制。此条件不省输入／native IDs、编辑／帮助等原操作，也不延期几何所需的首次准备；没有 backend 能力就不能省实际提交。首次出现、重新展开、滚入、错误及变更后的第一合法呈现 SHALL 有完整当前状态和相符几何／命中，不延后到后续帧摊账。

稀疏空白继承、显式 false／0、准确 domain、persist-first 结果、原非 Live 数值确认与已有 Live 立即发布、保存 debounce／反馈／失败与恢复 SHALL 保原 owner。确认／Live 的读回仍取原 owner 的当前采用值，不以旧展示快照或请求文本冒充 read-model。记录失败／未知环境时不能晋升完整成功凭据；新作用域失败沿 FL 采用的故障／完整同步路径，不以旧几何提供当前可操作命中。页面定义、widget／binding backing 或能力替换须重新确认资格，不能沿用旧来源凭据。关闭／替换使对应凭据失效并按原 owner 清理；关闭不重放提交或销毁业务数据。

#### Scenario: 生产展开后停手
- **GIVEN** 首次完整准备已成功，生产输入、UI 交互状态、几何和度量环境均有当前凭据
- **WHEN** 展开 F09 后无变化，经过后续合法输入／Repaint 回调
- **THEN** root 仍按合同观察来源，但不逐字段重建 effective／字符串／几何／展示描述；必要 native 操作及实际重画分别发生并计量

#### Scenario: 无 Bump 的真实失败结果
- **GIVEN** 征召全局域已展开，RowResult 原为空
- **WHEN** 原公开 `TryCommitActionField("volume", "not-a-number", "us.core/Draft", "", "")` 返回 false，业务 view／配置 revision 未变
- **THEN** 自有错误来源自动失效，结果行及其几何在第一合法呈现采用，不要求调用者另作 Notify／Bump，不复算无关字段

#### Scenario: 未提交 draft 改变错误和高度
- **WHEN** 原生数值输入改变 draft／valid／modified，而业务模型未提交
- **THEN** 原 editor 立即拥有该变化；新错误、反馈、布局与 hit 在正确回调反映，其他未变字段保持准备；IME、确认、失焦和 Cancel 不被快照吞掉

#### Scenario: 旧公开写入口不补通知
- **WHEN** 自有 source 的旧 setter、提交／拒绝／恢复或公开可变状态在合法条件下改变了原读面可见的 F09 输入
- **THEN** 生产 owner 的写边或边界观察发现变化；新准备消费当前 own／effective／结果／选择，不让旧调用者新增 Host／Notify 前提

#### Scenario: Live 与确认各守原义
- **WHEN** 已有 Live 操作发生或非 Live 数值执行 Enter／失焦确认
- **THEN** 分别沿原发布条件、准确 field/domain 和同一持久化 owner 执行；操作后的失效不重放提交，不把 accepted request／physical commit／publication success 混为一项

#### Scenario: 收起、重开与滚动
- **WHEN** 同一动作收起／重开，或字段滚入／滚出当前视口
- **THEN** retained keys、节点、draft 和精确对象不重建；当前 scroll／clip／hit 与 native ID 次序仍有效，首个应绘 Repaint 显示全部适用字段，不用旧坐标或少显示一帧换收益

#### Scenario: 字体尺寸语言或关闭变化
- **WHEN** theme、宽度／breakpoint／scrollbar、字体环境、语言／格式文化变化，或 Host 关闭／替换
- **THEN** 相应几何／paint／寿命凭据失效；未知度量保持原鲜读，颜色不无端毁掉草稿；新会话不复用旧 hit／editor，也不重放旧效果

#### Scenario: 无 opt-in 的旧消费者
- **WHEN** 页面、source、widget 或后端未明确采用所需保留能力
- **THEN** 原独立入口和普通 getter／同步 Draw／写／Live／故障条件仍可用；不强制 revision、可靠环境、先 Prepare 或新增通知

#### Scenario: 同 key 的 value 与 choices
- **GIVEN** 字段 value 与有序 choices 使用同一 binding key，二者均明确映射到新区域
- **WHEN** 只有选项 caption／help／成员或顺序改变，而当前 value 未变
- **THEN** 新准备从独立不可变 choices 通道采用当前选项，相关展示／几何失效；纯准备不借普通 Get／Choices 补读，原编辑写入与资格仍走原通道

#### Scenario: 布局在屏外但绘制范围未知
- **WHEN** 自定义字段 layout rect 不与 clip 相交，但不能证明实际 Paint 完全被裁尽
- **THEN** 所需 Repaint 照常 Paint；仅可复用已证明的准备，输入／native ID／帮助等原操作仍运行。证明或强制裁尽后只延期纯 Paint，滚入首个适用 Repaint 实画当前完整内容

#### Scenario: 当前父域关闭后不读旧子
- **WHEN** ordinary 父 VisibleBind 静默变 false，或 tab／Repeat 活动域移走旧字段
- **THEN** 按真实控制顺序停止旧子 getter；同一成员／几何事务协调当前树与 scroll／hit，不为证明未变调用已不可达业务对象
