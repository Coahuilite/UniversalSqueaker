# 正式UI消费、上下文与布局
状态：现行，US0.6.x。责任：US UI消费维护者。配置／提交与默认分别由CFG／PUB／POL拥有；本页只约束它们如何被真实界面消费，不另建业务规则。

## Purpose
从原生入口到包管理、直接工具和显式帮助，保同窗上下文、准确对象与可用输入。本文描述已定消费合同，不发起新的全局UX或工具页重做。

## Requirements

### Requirement: UI-01 三条路线进入同一窗口
US界面 SHALL履行以下已定消费与状态规则。

- 启动主菜单 **US 语音 / US Voices**。
- 原版设置类别栏 **US 语音 / US Voices**。
- 原 Mod Settings 重定向，作为隐藏前两项后的恢复路线。

“外观与入口”的 `showMainMenuEntry`、`showOptionsEntry` 独立保存，默认均 true；旧缺字段使用 true，已存 false 保留。它们只隐藏入口，不关闭面板、不改变声音政策。没有 MainButtonDef。

每个原生窗口仅创建一个 `UiHost`。重复打开保留窗口、host、页、域、搜索、滚动和 draft；原生 owner 将同一窗口插到其原有 WindowLayer 的正确最前位置，不跨过更高层确认框夺键。关闭时丢弃仅保留在编辑器内的未发布 draft；Live 已发布值保留，由同一保存 owner 在关闭时 flush／一次失败重试。重开是新会话。

#### Scenario: 重复进入已有窗口
- **WHEN** 通过任一入口再次打开
- **THEN** 保同一host与编辑上下文，仅在原WindowLayer合法置前，不越高层确认夺键


### Requirement: UI-02 首页先管理包，不承诺播放
US界面 SHALL履行以下已定消费与状态规则。

结构为标题与工具入口、真实配置／政策摘要、模式与全局音量、包／加载定义视图、常驻搜索、列表与对象详情。无五区侧栏、指标卡墙或永久 140 高帮助底栏。

P/Q 以独立 pack key 计数：Q 为当前目录身份，P 为至少在一个准确域已选用的目录身份。缺失已存选择另计，并在诊断页逐条列出域和 key，不伪装当前可用包。目录存在、被选中、具备可用声音与实际派发是不同事实；Dispatched 也不是听感收据。普通启动安装后首页说明普通回应就绪，仍按当前模式／选包／条件判断；尚未就绪时显示正常字号警示并直达诊断，状态代码留在诊断。显式开发方案单独说明，不伪装普通默认，也不提供暗启 Dev 的按钮。

单一目标显示精确域开关；多目标包先“查看内容”，在详情逐域开关。包名与内容按钮相邻，准确目标与开关相邻，剩余宽度留在组外。标题不批量启用。无歧义单目标不附加整行作者或来源；同名、异常、多目标才补最小辨识，完整作者、来源、DefName和覆盖留详情。长文本正常字号换行，列表和详情独立滚动。重复行以pack＋Race＋合法Xenotype身份保留节点，不按标签或索引认对象。查看包只改变查看身份，明确点域才切编辑目标，开关才写该准确域。当前包和域均从未过滤事实解析，隐藏对象保原身份和供给；无包、未加载、Biotech关闭、缺失选择与条件遮挡分明。返回列表与该层Esc保查询、页码、滚动和查看身份；显式取消选择另有含义，内层编辑／弹层／帮助仍优先。

包头与目标行 SHALL以自身文字和控件的自然高度参与列表；首项和后续项遵循同一规则。选中／悬停底板只跟随MatchContent，不制造独立行高。横向未占用宽度留在信息组外，不用同时消费纵向余量的空Fill容器占位，不硬编码首项高度、缩字号或改窗口断点掩盖空高。

详情 SHALL分别消费查看包与真实编辑域。没有查看包时只给短引导，不重复元数据或说明；没有合法可操作域时不显示“正在编辑”占位或无对象业务按钮。查看包不决定编辑资格，也不清已有独立域或来源；行为入口按真实Race／合法Xeno域，回退入口按实际父Race资格，显示、CanExecute与导航采用同一判定及准确身份。

包页默认类人且HAR优先；准确Human由加载Def对象身份确认，独立HAR类人范围排除Human。动物、其他、全部均可主动到达。复杂筛选可收起，范围、非默认条件、符合包数和本查询清除始终可见，关键词不重复为条件标签。Race／Xeno／作者候选独立有界搜索与翻页；输入搜索不选首项。无包Race／Xeno保候选和准确空态，无父域Xeno不编Human；未限定Race时同一Xeno Def合并，显示真实供包父域，同名不同Def按真实来源辨识。清除回包页类人默认，不清编辑目标／查看包／选包／行为来源。“已启用”在本次筛选投影保原合格行，关闭后真实开关立即false，刷新或更改筛选／搜索才重取成员。每页至多二十包是US投影分页；符合包数与全局P/Q分开，不逐帧扫描完整目录。

定义浏览来自加载的 ThingDef／Xenotype 目录，不是人口和音频供应反推；无包种族可见，异种操作仍受实际合法域限制。目录“打开”携带准确目标和包身份，不因显示需要改选择或模式。

#### Scenario: 已启用筛选内关闭一项
- **WHEN** 玩家关闭合格行
- **THEN** 实际开关立即false，当前筛选快照暂留行；刷新／更改查询才重取成员


### Requirement: UI-03 目录与回退表：先筛选，再翻页
US界面 SHALL履行以下已定消费与状态规则。

首次目录显示类人种族和加载异种；“仅种族／仅异种／HAR类人／准确Human及其真实供包异种／动物／其他／全部”是独立范围。HAR只决定框架标签与排序，不允许动物或机械越过默认生命类别门。没有Biotech时异种目录为空。加载异种的浏览身份不授予任意Race域操作权限；无真实父域保持独立身份。返回包列表再进目录及目录到达后返回，保关键词、类别、来源和页码。

关键词同时匹配名称、DefName和来源；来源筛选值是实际Def的packageId，显示模组名，同名追加ID。Core与每个DLC是不同来源，异种按自身XenotypeDef来源，不按基因或声音包归属。来源展开后可搜索，每页五项；结果每页八项，完整筛选排序后再分页。摘要对比符合数与完整合法总数，清除回本页默认。

已建回退表、新建Race候选与Core声音各有独立查询／来源／页码；已建表默认全部，Race候选默认类人，均可主动选择动物或其他生命类型。回退表不混入Xenotype。候选排除全部已建表，选择候选仅记录目标，明确按“创建”才落盘。筛选、来源和翻页都不落盘。当前编辑对象即使被筛掉或不在当前页，仍明确显示并保持原目标；选择另一表才切换编辑对象。

回退无表深链保目标，明确显示创建路径，不显示别的首表。保首次默认表时，仅在明确进入动作一次确认并同步state；投影、清除和翻页不自动采用。显示条目和声音写入共用同一已确认表身份，无确认表不暴露条目写入。来源选择器自己的搜索清除只清来源查询，不清当前列表或目标。

Core声音先取完整合法库存，再按关键词／来源筛选和排序，八项一页；不再不可达地截断前四十个声音或前二十个Race。声音不套生命类别，也不因此开放其他模组音源。每个窗口复用已发布定义快照，Core声音库存按该快照捕获；稳定Draw不重扫DefDatabase。新建Race接入仍需完整重启。

#### Scenario: 超过原前20／40库存
- **WHEN** 玩家翻页或搜索完整合法Race／Core声音集
- **THEN** 所有符合结果可达；选择新Race候选不落盘，明确创建才写


### Requirement: UI-04 七个二级工具，保留业务权威
US界面 SHALL履行以下已定消费与状态规则。

1. **行为与来源**：Pawn profile／Race／合法 Xeno 上下文，十五官方与实际 custom 动作、范围、有效值、来源和暂停理由。来源 dropdown 仅对合法域提供目录候选；继承不自动采用唯一候选。当前 action 的稀疏 enabled／interval／volume／pitch／talking／Age／Mood 由实际玩家行读取；空白继承，false 与 0 明确存在。字段编辑保留行中其他参数、响应贡献和模板恢复目标。
2. **预设导入**：保原目标选择和导入结果，只增量复制点名玩家字段；不串改作者来源或包选择。
3. **声音选取与输出**：保距离曲线／预设、彩蛋、谈话、Select 三资格、Eat 三轴；显示实际编辑域，提供行为页的作用域／逐动作音量音调入口。系统音量在首页可达。全局活跃度以可确认的正数输入接同一个 `GameSettings.activity`，默认1，不增加重复的秒数旋钮。
4. **最终回退表**：完整内容宽度和原独立取消层；从对象带 Race 深链。新 race 的 comp admission 仍要求重启，不能用 UI 刷新冒充。
5. **外观与入口**：三套单源数据色板只改角色色，不动字体、几何、滚动或编辑；相机指示器、两个独立入口开关，无独立缩放。
6. **诊断与依赖**：实际版本／固定依赖、缺失选择、普通回应诊断入口、日志及几何工具状态。回应窗口的显式单目标记录、复制和生命周期由 DIAG-06／07 拥有；打开后正常关闭暂停游戏的设置窗，不暗关草稿。Release 没有 Dev 几何能力时如实不可用，不启 Dev 规避。
7. **恢复设置**：先回当前域编辑器作单行／区域恢复；输出区域恢复独立。全局恢复在末尾折叠且保确认；来源意图／last-good 与独立回退文件仍按 r2 规则保留。

“设置与工具”直接打开本窗口上次工具，首次为行为与来源；不再有七按钮中转目录，也不把记忆写进配置。七类等宽 Button／Wrap 始终可直接切换，宽布局单排、紧凑布局三等列换行，末排不拉伸，不缩字号；包／定义和目录分组等同级导航也等宽。同级切换替换当前工具，不逐次压入返回历史；“返回语音管理”保留包、域、筛选、列表位置和仍由兼容节点持有的编辑上下文。帮助是当前业务正文下方的独立取消层，不替换原页。没有恢复全局五区侧栏。

footer SHALL对应PUB显示dirty／Saving／Saved／Failed，失败保显式Retry；普通排队不称Committed，原子已提交与发布失败分开。无全页Apply、无Draw写盘。

活跃度编辑消费POL-03，提供有限正值与有效来源，不增加重复秒数旋钮；仅取消受本区域恢复影响的草稿。

诊断查询空词回当前视口追踪行，非空词为有界当前地图搜索，最多返回64项并明确截断；返回数不是完整地图总数。就近清除只清诊断关键词并回第一页，保详情／记录目标。搜索不选择Pawn；点击保原视口内游戏选择／视口外锁定详情差异，窄屏返回保原查询、页码及滚动。原生IME、焦点与听感以实际证据单独验收。

#### Scenario: 工具切换与未提交草稿
- **WHEN** 同级工具直切再返回包管理
- **THEN** 保兼容节点的上下文和滚动；普通保存与原子结果沿PUB，不添加全页Apply


### Requirement: UI-05 帮助按需展开，不离开业务页
US界面 SHALL履行以下已定消费与状态规则。

页头“本页帮助”固定解释当前页，不读取此前 hover；字段／分组“说明”携带准确 topic 和打开时的 action／domain 对象。帮助是同一 Host 内正文下方的并列底栏，不覆盖业务、不叠窗。关闭时零占位，打开后从实际可分配正文区域取最多三分之一，排除页头、工具 Tab、页脚及本页边距；短文收缩，长文独立 Scroll，标题与关闭固定可见。消费层从公开安排结果读取正文起点、页脚和帮助标题高度，并以真实 ContentRect 的可用底边计算上限，不复制 FL chrome 常量。兼容 Definition 更新保留 Host、节点、业务／帮助各自滚动与草稿。

测绘只解析当前实际显示的译文、宽度与 Small／Tiny 字体，不遍历整目录求最大高度。帮助节点保留对应测量宽度的文字与分段高度快照，Draw 不再重测或把新正文塞进旧空间。未固定的独立消费者不需要 page-state／PreparePage：Draw 观察到主题变化或 grace 到期时只使本节点失效，在下一测量边界采用新正文；当前 pass 仍画已测文字。BeginHelpPass 清除即时 claim 后，上一 Draw 观察到的主题可交给该次测量，session 仍是唯一 15-pass 时钟。显式 pin 始终优先，正常页内发布／PreparePage 会立即测当前题，不被旧 hover 覆盖。宽度或字体环境不匹配时先重新测量再绘字。

当前文字、度量环境、内容／尺寸变化时才重新求底栏预算；不支持环境身份的 metrics 不假定测量可复用。正常固定 topic 不随 hover 改题；其他未固定帮助入口仍读 session 的 15-pass grace。目录ref（如us/mode-row/remix）、HelpItem.LabelKey／TextKey、binding地址（如help-section-ref）分别命名，不按显示标签或Value猜ref；目录定位后才翻译为实际文字。无选项专属帮助时保一般帮助，跨section显式ref仍可查目录；未知ref回原section，无section保空面板规则。

换不同工具页收起帮助；同页换 topic／对象回帮助顶部，同 topic 关闭再开保阅读位置。Esc 先走 FL 内层菜单／capture／编辑取消，再收帮助，最后业务返回。业务取消门在帮助打开时让位，不清业务对象、不提交草稿、不触发音频或来源编辑。

#### Scenario: 独立未pin帮助主题改变
- **WHEN** hover／15-pass到期使session主题变化但旧测量复用
- **THEN** 当前pass仍画已测文本，局部失效后才采用新文本；不把新长正文塞旧空间


### Requirement: UI-06 三套配色只作用 US
US界面 SHALL履行以下已定消费与状态规则。

“外观与入口”用一个 Dropdown 选择 **原版深色 `core`（默认）／Royalty `royalty`／黑金 `blackgold`**。选项、命名角色、显式颜色 aliases 仅来自嵌入 `Themes/Palettes.xml`，随 US DLL 交付，加载和校验一次；没有每帧 IO、热监视、额外编辑器或位置索引配置。非法内置数据仅一次可行动诊断，并保可打开的库默认颜色。

三套是当前交付数据，不是解析器的数量上限。解析验证非空集合、唯一 ID、稳定 `core` 默认、完整命名角色与合法颜色；角色还须通过实际 FL API 校验。默认调色板／accent／角色顺序均按 `core` ID 取得，不以文件首项代替默认身份。以后经授权增加配色只需扩同一数据文件，不为数量或排序改解析源码。

原版深色使用深炭底、清楚浅正文与克制金色交互；Royalty 保留夜蓝／暖金风格，是唯一 DLC；全新黑金为近黑底／浅字，金色只强调交互和选中。成功、警告、错误、禁用及 hover／选中分别有命名角色，必要状态同时保留文字／位置／形状。颜色不改字体、密度、控件几何、焦点、滚动或草稿。US widget 通过执行器的作用域绘制；原生入口在 finally 恢复 GUI.color／enabled、字体与锚点，不给整个原版菜单套 US 色板。

`appearanceSwatch` 原本就是字符串。`core`／`royalty` 保留，旧 `ideology`／`biotech`／`anomaly`／`odyssey` 及未知值修复到 `core`，在加载时只标记，主线程启动就绪后沿同一个保存 owner 排队并落盘；不在 GetSettings 期间调用尚未构建的 owner 或 Unity Time。缺省仍省略节点，恢复默认返回 core；不强改合法的 Royalty／黑金。

#### Scenario: 增加数据色板而默认顺序改变
- **WHEN** 数据包含合法新ID且core不在首项
- **THEN** 仍按稳定core默认，数量不写死；当前交付仍仅三项


### Requirement: UI-07 一份状态，两种真实编排
US界面 SHALL履行以下已定消费与状态规则。

仅使用 Verse 逻辑屏幕与 FL `BeforeDraw(contentRect)`，不另乘倍率、不改 Prefs.UIScale。初始外窗：

```text
W = max(1, min(1280, max(864, round(0.8 × Ws)), Ws − 64))
H = max(1, min(max(640, min(820, Hs − 128)), Hs − 64))
```

1024×768逻辑屏幕外窗为864×640，居中后左右80／上下64；更小屏幕按可用空间钳制，不强保下限。标题高36、无重复品牌副标题；普通状态并入包摘要，异常仍显式指向诊断。标准首页以三包完整名称／目标／启用状态为原生验收目标，更多包滚动。

从实际 FL contentRect 扣本页每边 12 的 padding，**页内宽 ≥1100 且高 ≥640** 才宽布局；在公共页头分配前决定。宽布局详情宽 440、间隔 16，列表取余量（断点处 644）；其余是真单区 drill-down／返回，不把两列压窄。

动态 InitialSizePolicy 由继承的 ResolutionChanged 通知重读；不每帧轮询物理屏幕。收到实际内容尺寸变化时关闭旧坐标 popup／capture；只有跨断点才更新 Definition，同一 host 和兼容节点保留，布局不调用保存／提交。页、域、筛选、列表 scroll 和 draft 都仍由原会话持有。

1024×768@1 与 1280×960@1.25 应紧凑；1366×768 宽而矮、1280×1024 窄而高均紧凑；1920×1080@1 及 @1.25 应宽；1920×1200@1.5 回紧凑。这些是源规则计算的预期，不是实机截图结论。原版拒绝的 1080p@1.5 不作为支持场景。

- **THEN** 真单区而非压窄两列；同host保页／域／草稿，旧坐标popup与capture关闭
