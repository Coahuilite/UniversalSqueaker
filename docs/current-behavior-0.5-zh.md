# 0.5.x 当前功能与设置

适用：保留的0.5.0历史行为，核对于2026-10-18；不是当前0.6功能合同。当前使用[唯一规格入口](specification.md)与[作者指南](us-kernel-0.6-authoring-zh.md)，旧Eat父子开关不进入新线。

## 让一个种族发声

1. 安装 US、前置模组 FerriteLib，以及适配准确种族的独立 VoicePack。
2. 在 **音频包 / Packs** 中选择 Race；异种包还需选择该 Race 下准确的 Xenotype，再勾选包。
3. 选择 **Fallback** 逐层回退，或 **Remix** 混合可用层。动作仍需满足触发条件、行为门控、冷却和可播放条件。
4. 包附带调音预设时，在 **预设导入 / Presets** 选择其声明的目标域并导入。勾选声音包不等于导入预设。

US 不附带自己的音频文件。当前仓库包含 Ratkin 的最终回退表与引用原版 Core 素材的用途 SoundDef；它们不是通用于所有种族的行为方案，也不会给其他种族自动提供声音。

## 模式决定从哪里选声音

| 模式 | 当前含义 |
| --- | --- |
| `Fallback` | XenotypePack → RacePack → PackFallback → BuiltInFallback，取第一个有结果的层 |
| `Remix` | 在当前非空层之间等权选层，再使用该层结果；三层和四层分支均跳过空层 |
| `Vanilla`（原版） | 只使用该种族的最终回退表；不是关闭 US |
| `Disabled` | 在生产入口旁路 US 发声逻辑 |

产品设置的 `Vanilla` 由适配器转为纯 Kernel 的 `SelectionMode.Off`；两者是不同层的命名，不是两个玩家模式，也不是 PackDef XML 字段。`Disabled` 在生产入口提前旁路。

`PackFallback` 只取当前精确域已勾选包的 fallback。Xenotype 上下文不会读取 Race 包的 fallback，但 Race 的普通动作音源仍是第二层。

最终回退表是显式的「动作 → 声音」映射，不是自动读取种族原版叫声。没有对应表或该动作映射时，末层可以无声。玩家可在 Packs 编辑最终回退表：已经获准接入的种族可刷新映射；原先没有 VoicePack 声明也没有表的新种族，首次添加表后需完整重启才会自动挂载。

## 服务域、安装与启用是三件事

- VoicePack 必须声明准确的 Race；Xenotype 包还要声明准确 Xenotype。相同 Xenotype 名不允许跨种族借用池子。
- 启动时自动挂载范围是「有效包声明的 Race」与「最终回退表的 Race」的并集，与玩家是否勾选包无关。已有作者 comp 会保留，US 不补写它的动作列表。
- 总览的种族浏览目录用于展示已加载对象，不授予发声资格。列表里看到种族，不意味着它有声音包、已有挂载或正在发声。
- Biotech 未启用、目标缺失或没有有效上下文时，运行时只能使用可用的 Race/Global 上下文。浏览目录和语音路由目录不是同一个目录。
- 添加、移除包或修改 Def/音频后重启游戏；设置中的勾选只是改变候选池，不是热加载模组。

## 五个工作区

| 工作区 | 主要操作 |
| --- | --- |
| 总览 / Overview | 种族概况与导航；全局音量、摄像机高度衰减和相机指示器；首次使用说明 |
| 音频包 / Packs | 筛选、准确 Race/Xenotype 域、包启用、最终回退表 |
| 规则与调制 / Tuning | 行为范围、间隔/概率倍率及心情调音；逐字段继承或覆盖 |
| 预设导入 / Presets | 导入作者提供的独立调音预设 |
| 高级与诊断 / Advanced | 诊断、主题与全局恢复 |

距离已不是独立工作区。底部帮助面板展开在页脚开关上方；主题切换只改变颜色，不改变声音设置、布局、滚动、焦点或编辑状态。

## 继承和全局控制不要混读

0.5.x 动作调音按 Xenotype → Race → Global → 默认解析，字段是否覆盖由 presence 标志表示。当前全局动作范围是可继承默认，局部可覆盖；它并不等同于不可绕过的全局总开关。

全局音量是输出倍率；当前播放入口把它与心情音量组合。玩家设置距离范围；摄像机位置／高度变化沿原版空间计算影响听感。当前实现会修改已知地图 SoundDef 的 SubSound 距离范围，因此共享这些 Def 的其他调用方也可能受影响。0.6.x 规格要求将这种效果改为 US 实例隔离，并让在播声音响应全局设置；这尚不是 0.5.x 已实现能力。

## 无声时按这条顺序排查

1. **包和目标**：是否有效、实际服务哪个 Race/Xenotype、是否在准确域启用。
2. **模式与动作**：是否 Disabled；动作是否开放；当前事实或事件是否真的对应动作。
3. **候选**：当前年龄、彩蛋开关、精确域回退是否留下可用声音；预览与生产门控不同。
4. **播放条件**：pawn、地图、可见范围、发声能力、冷却及概率结果。
5. **诊断**：查看 `usdiag` 和开发者诊断面板。`Dispatched` 表示交给后端，不是已经听见声音的确认。

当前异常和多种拒绝路径会消耗尝试冷却；不要根据静音推断冷却没有发生。具体当前逻辑见 [运行时架构](architecture-0.5-zh.md)，新结算规则见 0.6.x 规格。

## 设置与存档

设置和 fallback profile 副本位于游戏 Config 体系；US 不向殖民地存档写入永久业务数据。卸载后重启会移除运行时对 Def 的挂载。不要为排查文档问题删除玩家 Config、存档或重置全部设置。
