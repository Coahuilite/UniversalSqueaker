# 0.6.x 合同—验收与切片

S2实施及分层证据状态见[来源与资源S2](us-kernel-0.6-s2-zh.md)；V01/V08/V09/V10技术候选有自动证据，原生运行/听感及完整V14仍待其责任切片，以下合同不缩减。

本页是[首版规格 r4](us-kernel-0.6-spec-zh.md)的验收附页，合同覆盖S1–S5；当前分层证据以各切片实施页为准。C编号用于稳定引用同一行为；V编号沿用主规格。OneShot S1所需D1/D2/D5最小与D6入口/格式1已采用并有受控自动测试；未迁入部分仍按其切片裁定。Sustained新启动/替换不随本次采用批准，实际覆盖见OneShot S1实施页。数值均为测试输入，不是产品默认值。

## 核心只消费中性事实

C00（已定，主规格§2）：纯合同、决策、选音和参数合成只读中性值、准确身份及显式tick／随机输入。纯驱动与游戏适配调用同一核心，不另抄状态机。核心公开参数、返回值与泛型约束不得携带 Verse/RimWorld/Unity/Harmony 类型；纯测试工程不引用这些程序集，也不能以stub补齐它们。中性测量或定位只表达业务需要，不复制游戏对象模型。

适配所有者负责Pawn/Def查询、真实通知发生阶段、XML来源／资源绑定、Config读写、原生音频实例及其清理。它把事实与四类结果交给核心；不得在适配内重选动作、跨域找音、重抽随机、自写冷却。游戏版本变化应主要影响这些接缝。验收同时检查编译引用和真实转移结果，grep无游戏名称不能替代两者。

## S1 固定输入与期望转移（已采用OneShot范围）

### 一个自持fixture

- 对象`p1`，准确Race=`Ratkin`；另有`p2/Kiiro`作为域隔离对照。真实位置与器官均有效、系统/动作启用、Talking资格通过；Work的主动命令事实成立，scope为ActiveCommand，不改变旧默认条件。
- 状态动作Work成立，Call也成立但更低优先；Wounded仅由真实事件输入成立。本fixture候选稳定优先为Wounded > Work > Call；这是已采用的本切片关系，不给所有未来动作新增总排序。
- tick单位为游戏tick；截止等于当前tick时允许。Work/Wounded动作间隔各120、共用间隔40、失败重检R=60、状态等待W=20；初始所有截止已过，下一机会1000，无活跃实例。失败重检本例精确安排于公式给出的tick（主规格“之后”在本fixture指不得早于边界，实际调度可在该tick执行）。
- 两个Work条目同属Ratkin精确域，一层内权重1:3，按稳定条目键排序；当前fixture确定抽样值0.10命中第一个、0.90命中第二个。选音算法实际消费顺序由现有IRollSource计数器记录；用带标签的期望消费序列驱动，缺少/多余roll均失败，不能只设seed后忽略分支差异。
- 各案例从初始快照独立起步；除明确的连续轨迹，不串用前案冷却。后端为可控四结果驱动，不运行音频；默认OneShot，T04单独使用既有Sustained同键槽位。局部倍率/抖动均1；tick、事实与roll transcript一起保存，诊断不重抽。

**T06独立延迟变体（OneShot已采用，V03/V04）：** 从T02后的快照独立开始，原状态机会1060不变；到t1050才收到Wounded并Dispatched，动作/共用硬门均已过。确认Wounded=1050，H_Wounded=1170，H_shared=1090；未消费的状态机会须从1060推迟至1090，不是1110。不得重新抽W、追加原W=20，或让1060绕过新共用截止；除了事件自身已规定的随机，不消费新的状态等待随机。

T06中的Wounded间隔120仅为样本；旧入口是否有不同clock/门控按下方决策项裁定。概率资格拒绝、无成立动作、无候选或调制准备失败均必须有与T02相同的“未来重检、硬截止不更新”断言，但各自原因不同；不能全归成后端Rejected。
